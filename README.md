# كارطة السنابل
نسخة أولية قابلة للنشر على GitHub Pages دون build أو npm. تتضمن التدريب ضد الكمبيوتر، تسجيل الحساب بالبريد، غرف 2 و4 لاعبين، دعوات برابط، ملصقات، وحساب النقاط. المزامنة باستخدام RPC polling كل ثانية وليس Realtime WebSocket. لا تتضمن قائمة الأصدقاء الدائمة أو التصنيف أو لوحة الإدارة أو اللعب العشوائي أو الدردشة النصية أو الأصوات. القواعد التقليدية مبدئية: 40 ورقة، المطابقة المباشرة أولاً، نقاط الأغلبية في العدد والديناري والسبعات وسبعة الديناري والشكبات. ليست توثيقاً نهائياً للقواعد الليبية المحلية.

## الإعداد
1. في Supabase Dashboard افتح SQL Editor ثم New query والصق كامل `supabase/setup.sql` واضغط Run. لا يحتاج الموقع المفتاح السري. المفتاح العام وعنوان المشروع موجودان في `js/config.js`.
2. في Authentication فعّل Email. في URL Configuration ضع رابط GitHub Pages في Site URL وأضفه إلى Redirect URLs. أبقِ تأكيد البريد مفعلاً. قد تحتاج SMTP خاصاً حسب حدود الخدمة.
3. أنشئ مستودع GitHub باسم `karta-al-sanabel` وارفع محتويات هذا المجلد، بحيث يكون `index.html` في جذر المستودع. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. افتح رابط `https://USERNAME.github.io/karta-al-sanabel/` واستبدل USERNAME باسم حسابك. أنشئ حسابين مختلفين، افتح حساباً في كل متصفح، أنشئ غرفة وأرسل الرمز أو الرابط لصديقك، ثم ابدأ بعد اكتمال العدد.
5. إذا خرجت من الصفحة، انضم مرة أخرى بالرمز والحساب نفسه. لا توجد مهلة انسحاب تلقائية؛ الغرف تبقى محفوظة في قاعدة البيانات. لا يوجد نظام تنظيف تلقائي للغرف في هذه النسخة.

## تجربة محلية
من المجلد شغّل `python -m http.server 8000` ثم افتح `http://localhost:8000`. التدريب يعمل دون حساب؛ بعد تحميل ملفات PWA يمكن تشغيله دون الإنترنت. اختبار المحرك: `node tests/engine.test.mjs` (Node 22). اختبارات المحرك المحلي لا تثبت صحة SQL أو المصادقة أو اللعب عبر الإنترنت؛ يلزم اختبارها في مشروع Supabase بعد تشغيل SQL. لم يتم تنفيذ SQL على مشروعك من هنا.

## الأمان
لا تستخدم مفتاح sb_secret أو service_role داخل المستودع. إذا شاركت مفتاحاً سرياً فاحذفه من Supabase وأصدر بديلاً عند الحاجة. جدول الغرف في schema خاص غير مكشوف؛ وظيفة RPC تتحقق من المستخدم والعضوية والدور والأوراق وتخفي أيدي الخصوم. هذه نسخة أولية تحتاج مراجعة أمان واختبارات تكامل قبل إتاحتها للجمهور.
